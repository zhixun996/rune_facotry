# RuneFactoryOnline · 西幻网文设定库

> 版本：v0.3　｜　更新：2026-11-25　｜　维护：作者 + Claude

## 这是什么
本作品的所有设定、角色、大纲、细纲都存放在这里，**以本文件夹为唯一正本**。
任何会话（Claude 或作者本人）开工前，先读本文件和 `CHANGELOG.md`。

## 目录
| 路径 | 内容 | 负责会话 |
|---|---|---|
| `00_项目概要.md` | 书名、基调、卖点、一句话梗概、核心矛盾 | 世界观会话 |
| `01_世界观/` | 地理、历史、力量体系、种族、势力、宗教、社会经济 | 世界观会话 |
| `02_角色/` | 角色总表与单人档案 | 世界观会话（大纲会话可提议） |
| `03_大纲/` | 总大纲、分卷大纲、待补设定清单 | 大纲会话 |
| `04_细纲/` | 按卷/章的细纲 | 大纲会话 |
| `99_名词表.md` | 专有名词统一写法与一句话释义 | 所有会话（只增不改含义） |
| `CHANGELOG.md` | 全部改动记录 | 所有会话 |

## 协作规则
1. **一份文件只由一个会话负责写**。其他会话需要改动时，写进 `03_大纲/待补设定.md`，再交给负责会话处理。
2. **每次改动**：更新该文件头部的版本号与日期，并在 `CHANGELOG.md` 顶部追加一条。
3. **版本号规则**：`v主版本.次版本`
   - 次版本 +1：补充细节、新增条目、措辞修改
   - 主版本 +1：推翻或改写已定设定（必须在 CHANGELOG 写明“原设定 → 新设定”及原因）
4. **设定状态标记**：`【定】` 已确定　`【拟】` 暂定可改　`【废】` 已废弃（保留记录，不删除）
5. 专有名词首次出现时登记到 `99_名词表.md`，后文统一写法。

## 版本管理（Git，由作者提交）
- 版本历史以 Git 为准，**提交和推送由作者手动执行**，Claude 不操作 Git、不另存旧版文件。
- Claude 每次改完文件，在回复末尾给出一行提交命令，作者确认无误后运行：
  ```
  git add -A && git commit -m "[模块] 文件名 vX.X 改动摘要" && git push
  ```
- `CHANGELOG.md` 仍需同步追加：Claude 的会话看不到 Git 历史，靠它了解之前改过什么。
- 需要回退时由作者用 Git 操作；回退后告诉 Claude，以便同步 CHANGELOG。
